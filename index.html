📖 API Documentation

            

                
API 1: GET /api/portfolio/balance

                
Returns current portfolio balance, 24h change, and total holdings.

                

                    
Response Example:
{
  "status": "success",
  "data": {
    "totalValue": 250000.00,
    "change24h": 2.34,
    "holdings": 7,
    "currency": "USDT"
  }
}

                


                
API 2: GET /api/crypto/prices

                
Fetches current price data for selected cryptocurrency.

                

                    
Response Example:
{
  "Network": "Ethereum",
  "data": {
    "symbol": "ETH",
    "price": 26.79,
    "marketCap": 27000000000,
    "volume24h": 12000000000
  }
}

                


                
API 3: POST /api/verify/access

                
Verifies API access through blockchain confirmation or QR code scanning.

                

                    
Response Example:
{
  "status": "success",
  "data": {
    "verificationAddress": "0x4bea2d3B8Ecb9b283350Db91dcC540C3e9C8be62",
    "verificationMethod": "blockchain",
    "timestamp": "2026-08-20T14:30:00Z",
    "status": "verified"
  }
}

                


                
API 4: POST /api/bank/transaction

                
Handles bank deposits and withdrawals with KYC verification.

                

                    
Request Body:
{
  "type": "USDT TRANSFER",
  "currency": "USDT",
  "amount": 250000,
  "Network": "Ethereum"
}

Response Example:
{
  "status": "success",
  "data": {
    "Recipient Address": "0x56eddb7aa..d21a8b17f",
    "amount": 250000,
    "estimatedArrival": "After API VERIFICATION is completed",
    "status": "pending"
  }
}
